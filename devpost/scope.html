ScopeLock

A local-first scope protection engine that turns client briefs into approved baselines and compares new requests to make scope creep visible before work expands.

✦ The Unique Kernel

Unlike conversational AI that offers ungrounded opinions, ScopeLock anchors every incoming request to an explicit, human-approved baseline version, explains matches and gaps with evidence, and preserves an immutable local decision history.

SYSTEM FLOW & PROOF-OF-CONCEPT LOOP
Target User & Problem

Target: Freelance software developers and boutique agencies handling casual client requests across email, Slack, and calls.

Problem: Initial agreements are scattered. Follow-up requests arrive casually, making it awkward and difficult to prove whether something was included or adds scope before unpaid work begins.

What "Working" Looks Like

Paste a client request: ScopeLock immediately displays the matched items (or what is missing), assigns a clear status, provides a plain-language rationale, and lets the developer log a decision.

The entire interaction survives browser refreshes and can be exported as a JSON audit trail with one click.

Boundary Management
  • Local project creation with named workspace
  • Paste brief, edit/add/delete extracted scope items
  • Explicit baseline versioning with timestamped human sign-off
  • Transparent comparison engine (IN_SCOPE, POSSIBLE_CHANGE, NEEDS_REVIEW)
  • Plain-language rationale and uncertainty notes tied directly to baseline items
  • Human decision logging (Accept, Reject, Clarify) with notes
  • Persistent decision history that survives page refresh
  • One-click JSON export and full local reset
  • Zero external credentials, zero network transmission (100% private)
