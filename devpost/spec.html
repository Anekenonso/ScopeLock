Technology Decisions & Architecture Boundaries
  • Next.js (App Router, React 19, TypeScript): Chosen for its production structure and clean typing. Keeps V1 pure client-side while offering an easy path to server routes and extensions in V2/V3.
  • Zod Schema Engine: Ensures all reads and writes to browser localStorage are validated against explicit runtime schemas. If corrupted data is detected, it fails gracefully without crashing the UI.
  • Pure Isolated Comparator: The comparison engine is a standalone TypeScript class implementing ScopeComparator. Decoupled from React and storage so it can be tested in headless environments and swapped in future versions.
  • Zero External Dependencies / Secrets: Requires no API keys, no backend databases, and makes no network requests. 100% private to the user's browser.

export const DecisionRecordSchema = z.object({
  id: z.string(),
  requestId: z.string(),
  requestText: z.string(),
  status: z.enum(["IN_SCOPE", "POSSIBLE_CHANGE", "NEEDS_REVIEW"]),
  matchedItemIds: z.array(z.string()),
  rationale: z.string(),
  uncertaintyWarning: z.string().optional(),
  action: z.enum(["ACCEPT", "REJECT", "CLARIFY"]),
  note: z.string().optional(),
  baselineVersionId: z.string(),
  baselineVersionNumber: z.string(),
  decidedAt: z.string(),
});

Verification Sequence & Evidence Gates
  • Gate 0: Foundation Setup: Initialize Next.js, TypeScript, Tailwind, Zod, and Vitest test harness.
  • Gate 1: Kill-Test Verification: Implement deterministic.ts and execute tests/unit/comparator.test.ts. Require 100% pass on all 12 cases before UI work.
  • Gate 2: Storage & Ingestion Slice: Implement briefParser.ts and repository.ts. Verify baseline creation, draft editing, and version bumping (`v1.0` -> `v2.0`).
  • Gate 3: End-to-End Vertical Slice: Connect UI split-view workspace. Verify brief paste -> baseline approval -> request compare -> decision logging -> browser refresh.
  • Gate 4: Edge Cases & Reliability: Verify empty state, corrupted storage recovery, JSON export, and confirmed project reset.
